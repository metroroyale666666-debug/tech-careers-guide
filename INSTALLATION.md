# 📚 Инструкция по использованию и редактированию презентации

## Требования

Для работы с этой презентацией вам понадобится:

1. **LibreOffice Impress** (бесплатный офисный пакет)
   - Скачать: https://www.libreoffice.org/download/download/
   - Работает на Windows, macOS, Linux

2. Или альтернативные программы:
   - Microsoft PowerPoint (платная)
   - Google Slides (онлайн, бесплатная)
   - Keynote (для macOS)

## Установка LibreOffice (рекомендуется)

### Для Windows:
1. Перейдите на https://www.libreoffice.org/
2. Нажмите "Скачать"
3. Выберите "LibreOffice Impress"
4. Скачайте установщик
5. Запустите установку и следуйте инструкциям
6. После установки можно открывать файлы .odp

### Для macOS:
1. Перейдите на https://www.libreoffice.org/
2. Скачайте версию для macOS
3. Откройте dmg файл
4. Перетащите LibreOffice в папку Applications
5. Готово!

### Для Linux:
```bash
# Ubuntu/Debian
sudo apt-get install libreoffice

# Fedora
sudo dnf install libreoffice

# Arch
sudo pacman -S libreoffice
```

## Как скачать файлы из репозитория

### Способ 1: Скачать весь репозиторий
1. Перейдите на https://github.com/metroroyale666666-debug/tech-careers-guide
2. Нажмите зелёную кнопку "Code"
3. Выберите "Download ZIP"
4. Распакуйте архив на компьютер

### Способ 2: Скачать отдельный файл
1. Откройте нужный файл в репозитории
2. Нажмите иконку "Raw" (справа)
3. Нажмите Ctrl+S (или Cmd+S на Mac)
4. Сохраните файл

## Как открыть презентацию

### Если файл уже создан (presentation.odp):
1. Найдите файл на компьютере
2. Щелкните правой кнопкой мыши
3. Выберите "Открыть с помощью"
4. Выберите "LibreOffice Impress"
5. Файл откроется в программе

## Как создать новую презентацию с нуля

### Шаг 1: Открыть LibreOffice Impress
- Windows: П��ск → Поиск → LibreOffice Impress
- macOS: Spotlight → LibreOffice Impress
- Linux: Приложения → LibreOffice Impress

### Шаг 2: Создать новую презентацию
1. Нажмите "Файл" → "Создать" → "Презентация"
2. Выберите пустую презентацию
3. Начнется создание новой презентации

### Шаг 3: Добавить слайды
1. Нажмите "Слайд" → "Создать слайд" (или Ctrl+M)
2. Выберите макет слайда (заголовок, содержание и т.д.)
3. Добавьте текст, нажав на текстовые поля

### Шаг 4: Добавить содержание
Используйте содержание из файла `presentation-slides.md`:
- Скопируйте текст для каждого слайда
- Вставьте в соответствующий слайд в LibreOffice
- Отформатируйте текст (размер шрифта, цвет и т.д.)

### Шаг 5: Добавить изображения
1. Щелкните "Вставка" → "Изображение"
2. Выберите изображение на компьютере
3. Нажмите "Вставить"

### Шаг 6: Форматирование
1. Выберите текст или объект
2. Используйте панель инструментов для изменения:
   - Шрифта
   - Размерa
   - Цвета
   - Выравнивания

### Шаг 7: Сохранение
1. Нажмите "Файл" → "Сохранить как"
2. Выберите формат "ODP (OpenDocument Presentation)"
3. Дайте имя файлу: `presentation.odp`
4. Выберите папку для сохранения
5. Нажмите "Сохранить"

## Экспорт в другие форматы

### Экспорт в PDF
1. Нажмите "Файл" → "Экспортировать как" → "Экспортировать в PDF"
2. Выберите параметры экспорта
3. Нажмите "Экспортировать"
4. Выберите папку и имя файла

### Экспорт в PowerPoint (.pptx)
1. Нажмите "Файл" → "Сохранить как"
2. В формате выберите "Microsoft PowerPoint 2007-365"
3. Нажмите "Сохранить"
